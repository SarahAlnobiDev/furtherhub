# 🌟 FurtherHub: Academic Resource Management System 🎓

> 🏆 **2nd Place – Artifact 4 Student Projects Exhibition**  
> **Female Students Category | College of Computers and Information Technology | University of Science and Technology**

**FurtherHub** is a Python-based desktop application designed to make academic resources easier to share, organize, and access among students.

The project addresses the delays that can occur when academic materials depend on a single intermediary by providing students with a structured peer-to-peer platform where they can directly share and discover useful academic resources.

> **Note:** The application interface is fully in Arabic and is currently tailored specifically for Computer Science students.

---

## ✨ Key Features

- **Direct Peer Sharing:** Students can share summaries, useful links, and academic resources directly through the platform.
- **Smart Categorization:** Resources are organized by subject, resource type (YouTube, PDFs, Exam Samples), and major.
- **Dynamic Rating System:** A star-rating and comments system helps students evaluate the usefulness and quality of shared materials.
- **Modern UI/UX:** A modern desktop interface with dark and light modes for a comfortable user experience.
- **Lightweight & Fast:** Uses SQLite for efficient local data storage and management.

---

## 💻 Technologies Used

- **Python** – Core application logic.
- **CustomTkinter** – Modern graphical user interface.
- **SQLite** – Local relational database and data management.
- **Pillow** – Image processing and interface assets.

---

## 🔮 Future Improvements

Our roadmap is to evolve FurtherHub into a more comprehensive academic resource platform.

- **Comprehensive Academic Coverage:** Expand the platform to cover more Computer Science departments, subjects, and study materials.
- **Advanced Search & Filtering:** Add faster and more flexible search and filtering capabilities.
- **Direct File Hosting:** Allow students to upload PDFs, slides, and other academic files directly to the platform.
- **AI-Powered Quality Control:**
  - Integrate AI models to help evaluate and verify uploaded resources before publication.
  - Introduce smart comment moderation to support a helpful and professional community.
- **Smart Resource Ranking:** Rank and prioritize resources based on user ratings and future AI-assisted quality scores.

## 🚀 How to Run

1. **Clone the repository:**

   ```bash
   git clone https://github.com/SarahAlnobiDev/furtherhub
   ```

2. **Install dependencies:**

   ```bash
   pip install customtkinter pillow
   ```

3. **Run the application:**

   ```bash
   python main.py
   ```
